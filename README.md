# Ph.D. Multi-PDF RAG & Systematic Literature Review Assistant

A lightweight, open-source Retrieval-Augmented Generation (RAG) tool built with **Streamlit** and **LangChain** to help researchers parse multiple research papers, analyze methodologies, track contradictions, and surface research gaps without expensive commercial subscriptions.

## 🚀 Features
* **Multi-PDF Ingestion:** Upload and parse multiple academic papers simultaneously.
* **Semantic Search & Q&A:** Query your local literature corpus using natural language.
* **Systematic Synthesis:** Extract methodologies, author-stated limitations, and unaddressed gaps.
* **Cost-Free & Private:** Run locally or via free-tier cloud stacks to maintain complete data privacy.

## 🛠️ Tech Stack
* **UI:** Streamlit
* **Orchestration:** LangChain
* **Vector Store:** FAISS / Chroma
* **LLM Integration:** OpenAI / Open-Source Local Models
